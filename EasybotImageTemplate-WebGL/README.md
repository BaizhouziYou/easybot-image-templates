# 服务器在线列表

版本：**1.2.0**；作者：**BaiZhouziYou**。

模板 ID：`server_player_count`；模板 key：`player_count`。

![服务器在线列表预览](preview.png)

## 功能

- 汇总多台服务器的在线人数，按服务器展示玩家列表。
- 单台服务器查询失败时保留其他服务器结果，并标记失败分组；汇总人数显示为 `7+` 这样的已知人数下限，整体状态显示“部分异常”。
- 支持服务器显示筛选、仅显示在线服务器及基岩版玩家标识。
- 支持国内头像源、Blessing Skin / LittleSkin 和自定义头像地址；支持混合头像源顺序与加载失败回退。
- 支持经典深色与 WebGL 液态玻璃，提供外观、折射范围和光照方向设置。
- 支持默认背景、随机背景、自定义图片、纯色背景及暗化程度设置。
- 支持多档输出清晰度，内置 Noto Sans SC 和思源黑体，也可使用系统字体。
- 提供图形化配置、预览编辑、自定义 CSS、数据缓存、头像缓存及 Debug 日志。

## 使用

运行需要支持图片模板的 EasyBot、图片渲染器和已接入的 Minecraft 服务器。由 EasyBot 调用模板后，在设置页选择需要展示的服务器、头像源、背景与主题，保存配置并验证出图。

`index.html` 为图片页面，`settings.html` 为设置页面，`manifest.json` 为模板清单。保留原模板 ID 和配置键，已有配置可继续沿用。

默认头像地址为 `https://api.skin.xintinglei.cn`，随机背景地址为 `https://t.alcy.cc`，均可在配置页调整。仓库不包含这些服务的实现或下载图库。外部服务不可用时，可以切换为无需远程图片的背景配置并调整头像源。

液态玻璃和高分辨率会增加渲染开销；需要更快出图时可使用经典主题、降低输出清晰度并开启缓存。实际渲染等待时间应按服务器和图片源情况调整。
