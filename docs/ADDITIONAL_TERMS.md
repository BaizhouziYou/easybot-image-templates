# EasyBot Image Templates 附加条款

本条款作为 GNU AGPL v3.0 的补充，适用于本项目中由 BaiZhouziYou 享有版权的内容。本条款沿用新亭泪官网的署名与来源声明方式，旨在 AGPL 第 7(b)、7(c) 和 7(e) 条允许的范围内生效。

## 署名与源码声明

当修改版通过交互式用户界面呈现时，应在设置页、关于页、致谢页或法律声明页保留合理可见的声明，包含以下内容：

1. 项目名称 `EasyBot Image Templates`；
2. 明确说明该修改版基于或使用 EasyBot Image Templates；
3. 指向 [项目声明](../NOTICE.md) 中原始源码仓库的链接，或该项目的忠实公开镜像链接。

合规示例：`基于 EasyBot Image Templates · 源码`，其中“源码”应链接至原项目仓库或其公开镜像。

不得故意隐藏、遮挡声明，或使其实际上难以辨认。修改版还应在源码声明中注明已经修改，并记录相应的修改日期。署名可以放在模板设置页，本条款不要求在每张生成图片上添加水印。

## 对应源码

当 AGPL 第 13 条适用时，应向与修改后的网络部署交互的用户提供清晰、免费的途径，以获取实际运行版本的完整对应源码。仅链接至未经修改的上游版本，不能代替提供修改部分的源码。
