# 关于渲染过慢问题

可在渲染时机中选择“自定义渲染时机”，完成时机设置为 `Networkidle0`，渲染延迟设置为 `1.0s`，其余选项保持不变。

启用 WebGL 液态玻璃或较高输出分辨率后，渲染耗时与性能占用会有所增加。若更注重生成速度，可使用经典深色主题、标准或高清分辨率，并开启性能数据缓存。

# 特别功能

- 支持查询 TPS、MSPT、CPU、内存、在线人数等服务器性能信息
- 支持在同一张图片中按分组显示多台服务器，并自由选择显示或隐藏哪些服务器
- 支持每台服务器独立设置变量预设、PAPI 查询玩家名、指标配置和模板显示名称
- 支持 Bukkit / Paper 与 Fabric 变量预设
- 支持自定义 PAPI 变量、显示单位、判断方式和状态阈值
- 根据阈值自动标记正常、警告、危险与未知状态
- 支持一次配置最多 18 个性能指标
- 支持性能查询结果缓存，降低重复生成耗时
- 支持经典深色与 WebGL 液态玻璃主题
- 液态玻璃支持清澈、着色外观以及折射范围、光照方向调节
- 支持默认背景、随机背景、纯色背景与自定义图片
- 支持更高清的输出效果
- 内置中文字体，避免 Linux 环境缺少中文字体导致显示异常
- 提供图形化配置、预览编辑、Debug 日志与自定义 CSS
- 支持高度自定义

## 详细功能清单

- 支持同时查询多台服务器的 PlaceholderAPI 变量，并按服务器生成独立分组
- 可在服务器列表中全部显示、全部隐藏或逐台勾选
- 每台服务器可独立使用 Fabric、Bukkit / Paper 或完全自定义的变量配置，适合插件端与模组端混合部署
- 支持为每台服务器设置独立的 PAPI 查询玩家名
- 支持自定义服务器在模板中的显示名称，留空时沿用 EasyBot 服务器名
- 单台服务器离线或变量查询失败时只影响对应分组，不会阻断其他服务器显示
- 支持 TPS、MSPT、系统 CPU、进程 CPU、已用内存和在线玩家等默认项目
- 提供 Fabric 1.19+（Text Placeholder API）变量预设
- 提供 Bukkit / Paper（PlaceholderAPI）变量预设
- 应用变量预设后仍可自由增删和修改指标
- 每行指标支持配置：名称、PAPI 变量、单位、判断方式、警告值和危险值
- 支持 `lower` 判断方式，用于 MSPT、CPU 占用等数值越高越差的项目
- 支持 `higher` 判断方式，用于 TPS 等数值越低越差的项目
- 支持 `neutral` 判断方式，仅展示数值而不参与健康状态判断
- 自动汇总各项指标状态并显示服务器整体健康情况
- 未解析、返回空值或不可用的变量统一显示为 `--`
- 自动清除返回值中的 Minecraft 颜色与样式控制符
- 多个 PAPI 变量优先合并为一次请求，返回格式不兼容时自动逐项查询
- 支持逐服指定 PAPI 查询玩家名，为需要玩家上下文的变量提供解析对象
- 支持缓存性能查询结果
- 支持设置 5 秒、15 秒、30 秒、1 分钟或 5 分钟缓存时间
- 修改显示服务器、逐服指标、显示名称或查询玩家后会自动使用新的缓存键
- 支持显示服务器数量、更新时间、监控指标总数与跨服务器整体状态
- 支持自定义主标题、标题上方信息、说明文字和服务器标签
- 支持经典深色主题
- 支持 WebGL 液态玻璃主题
- WebGL 不可用、随机背景或跨域背景场景下支持静态边缘折射回退
- 液态玻璃支持清澈与着色两种外观
- 支持调节液态玻璃边缘折射范围
- 支持调节液态玻璃光照方向
- 支持标准、高清、超清、极清等多档输出分辨率
- 支持默认背景、自定义图片、随机图片和纯色背景
- 随机背景支持类似于 `https://t.alcy.cc/moez` 的直链随机图接口
- 随机图片 API 支持使用 `{category}` 指定分类插入位置
- 随机图片分类支持二次元、电脑横图、手机竖图、风景与自定义参数
- 自定义随机图片分类允许留空，也可追加路径、查询参数或锚点参数
- 纯色背景支持 `#RGB`、`#RGBA`、`#RRGGBB` 和 `#RRGGBBAA` HEX 颜色码
- 支持调节背景暗化程度
- 内置 Noto Sans SC
- 内置 Source Han Sans SC / 思源黑体
- 支持使用系统默认字体
- 支持自定义 CSS
- Debug 模式默认关闭
- Debug 模式支持记录配置、渲染上下文、接口、缓存、字体、背景、液态玻璃和渲染尺寸日志
- 支持导出、清空 Debug 日志
- 支持手动清空性能数据缓存
- 提供图形化配置页面
- 提供预览编辑页面

## Fabric 使用说明

- Fabric 1.21.4 可使用 EasyBot Fabric Mod
- 必须安装 Fabric API
- 需要扩展服务器性能变量时，请安装 Text Placeholder API
- 系统 CPU、进程 CPU 等 Spark 指标需要安装 Spark
- Fabric 不需要也不能使用 Bukkit 的 `/papi ecloud download` 指令，将模组放入 `mods` 目录并重启服务器即可
- 在模板配置中打开“服务器与性能变量”，找到对应 Fabric 服务器，选择 Fabric 预设并点击“应用所选预设”，然后保存

Fabric 预设使用的主要变量：

- `%server:tps%`
- `%server:mspt%`
- `%server:used_ram%`
- `%server:online%`
- `%spark:cpu_system 10s%`
- `%spark:cpu_process 10s%`

若 TPS、MSPT、内存和在线人数正常，但 CPU 显示为 `--`，请检查 Spark 是否已安装并成功加载。服务器刚启动时，可等待统计窗口产生数据后重新生成。

## Bukkit / Paper 使用说明

- 需要安装 PlaceholderAPI
- Spark 性能变量需要安装 Spark
- 其他自定义指标所需扩展请根据对应插件文档安装
- 在模板配置的服务器列表中找到对应服务器，选择“Bukkit / Paper（PlaceholderAPI）”预设，或直接填写该服务器实际可用的 PAPI 变量

不同服务端、插件或模组提供的变量名称可能不同。模板不会伪造缺失数据，无法解析的指标会显示为 `--`。
